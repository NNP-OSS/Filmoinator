# Filmoinator

## Instalacja:

1. Zainstaluj docker: https://docs.docker.com/desktop/setup/install/

2. Sklonuj repozytorium:

```bash
git clone https://github.com/NNP-OSS/Filmoinator.git
cd Filmoinator
```

3. W docker-compose.yml dotosuj:

   - Login i hasło administratora
   - Port

4. Uruchom:

   ```bash
   docker compose up -d
   ```
